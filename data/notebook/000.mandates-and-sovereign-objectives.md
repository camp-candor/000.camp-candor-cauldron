### **I. The Lingua Franca: JSON-LD (The Ontology)**

**The Schema:**

```json
{
  "@context": "https://www.w3.org/ns/activitystreams",
  "type": "Object",
  "id": "https://api.niflheim.com/items/sword_882",
  "name": "Blade of the Ancestor",
  "attachment": {
    "type": "Weapon",
    "damageType": "Slash",
    "dps": 45.2,
    "provenance": "https://api.niflheim.com/history/kill_log_2024"
  }
}
```

- **The Architecture:**
  - **Internal:** `ItemDO` holds `damage: 45`.

### **II. The Customs Agent (The Cloudflare Gateway)**

1.  **Ingress:** Visitor enters with `Item: "Neutron Armor" (Tags: SciFi, Heavy, High_Defense)`.
2.  **Lookup:** The Node.js Translator Service queries Neo4j:

3.  **The Result:** Neo4j finds the nearest semantic match: **"Enchanted Plate Mail"**.
4.  **The Projection:** The server renders the visitor wearing Plate Mail.
    - _Note:_ We do not change their data. We only change our _perception_ of their data. To them, they are wearing space armor. To us, they are a weirdly shiny knight.

## I. THE SIX PILLARS OF THE COVENANT

These are not guidelines. These are **Structural Load-Bearing Walls**. If one is removed, the architecture collapses.

### **PILLAR I: THE PHYSICS OF TRUTH (Infrastructure)**

_The Hardware of Reality._

**The Law:** **Reality is Local, Atomic, and Sharded.**
To defeat the speed of light, we must bring the calculation to the user. To defeat the database lock, we must fracture the world into thousands of isolated universes.

1.  **The Hex Mesh (Cloudflare Durable Objects + H3):**
    - **Topology:** The world is mapped to a hierarchical **Uber H3 Grid**.
    - **The Atom:** The **ZoneDO** (Resolution 8 Hex) is the fundamental unit of physics. It acts as a Single-Threaded CPU for that specific geographic acre.
    - **The Routing:** We reject the central database lookup. Routing is **Deterministic**. The Client calculates the server ID using `Hash(Coordinates)`. There is no "Load Balancer"; there is only Geometry.
    - **The Memory:** Active simulation happens exclusively in **V8 Heap (RAM)**. We do not query the disk for combat physics. Disk I/O is death to the 100ms mandate.

2.  **The Nomad (PlayerSessionDO):**
    - **Role:** The Soul.
    - **Mechanism:** Player Data (Inventory, Stats) lives in a Durable Object that is logically detached from the world geometry.
    - **Interaction:** The **Zone** (Body) executes the physics. The **Nomad** (Soul) records the consequences via asynchronous RPC. This separation ensures that if a Zone crashes (The World breaks), the Player does not lose their save file.

3.  **The Cortex (Neo4j - Graph Database):**
    - **Role:** The Deep Memory / Long-Term Causality.
    - **Integration:** The Graph does not run physics. The Graph stores **Complex Topology** that requires traversal deeper than 1-hop.
    - _Usage:_ "Who is the cousin of the man I just killed?" or "Which faction controls the supply chain of iron?"
    - _Latency Constraint:_ Queries to the Cortex are **Asynchronous**. They inform the Narrative; they do not block the Sword Swing.

### **PILLAR II: THE IRON INTERFACE (Protocol)**

_The Immunology of the System._

**The Law:** **Trust Nothing. Verify Everything.**
Systems degrade because developers create backdoors. We seal the doors.

1.  **The API is the Only Truth:**
    - Communication between services (`Economy` -> `Zone`) uses **Strictly Typed Contracts** (Protobuf / JSON Schema).
    - **No Global Variables.** No Shared Memory between Shards. If it isn't in the API payload, it doesn't exist.

2.  **The Dogfood Directive:**
    - The React Frontend (Client) uses the **exact same API** as the internal microservices.
    - If the developer creates a "God Function" to bypass the API for convenience, they introduce a security vulnerability. This is heresy.

3.  **The WebSocket Tunnel:**
    - We reject Polling. We reject REST for high-frequency state.
    - **Multiplexing:** Narrative Text (Streamed tokens) and Physics State (Binary coordinates) travel down the **same** persistent TCP socket managed by the Nomad. This prevents "Split-Brain" desync where the client reads text describing a death before it receives the packet confirming the kill.

### **PILLAR III: THE METABOLISM OF DATA (Logic)**

_The Separation of Math and Poetry._

**The Law:** **Math Precedes Poetry.**
We solve the "Hallucination Problem" by enslaving the Generative Model to the Deterministic Engine.

1.  **The Hierarchy of Execution (The Sportscaster Model):**

    - **Phase 3: The Narrative Engine (Generative):** The LLM receives the Fact Block. Its System Prompt explicitly forbids it from altering the numbers. Its only job is to describe the _sensation_ of the Fact.

2.  **Input Sanitation:**

### **PILLAR IV: THE ARCHITECTURE OF MEMORY (Persistence)**

_The Laws of Time and Recovery._

**The Law:** **RAM is Speed. Disk is Safety. Logs are Resurrection.**

1.  **The Cache Stratum:**
    - 100% of Active Gameplay occurs in **V8 Isolate RAM**. This is the only way to achieve sub-100ms interactions for complex systems.

2.  **The Write-Ahead Log (WAL):**
    - Before any Critical State Mutation (Trade, Death, Level Up) is applied to RAM, it is appended to a **Persistent Append-Only Log** in the Durable Object Storage.
    - _Crash Recovery:_ If the server dies, it reboots and replays the WAL. The timeline is restored perfectly.

3.  **The Cold Archive (R2):**
    - Inactive Zones and Offline Players are serialized into compressed JSON/Binary blobs and flushed to **Object Storage (R2)**.
    - This is the "Sleep" state. It costs fractions of a penny.

4.  **The Vector Index (Deep Retrieval):**
    - **Lore** and **History** are chunked and vectorized (embedded).
    - They are stored in **Cloudflare Vectorize** (for speed) or **Neo4j Vectors** (for graph-aware search).
    - This allows the AI to "remember" facts from 1,000 pages of text by performing Cosine Similarity searches, injecting only the relevant context into the immediate prompt.

## IV. FAILURE STATES & RECOVERY PROTOCOLS

_If you build a ship, you must understand how it sinks._

**1. THE SPLIT-BRAIN FRACTURE**

- _Scenario:_ A player trades an item to another player while crossing a Zone boundary. Network partition occurs.
- _Protocol:_ **Two-Phase Commit.** The item is placed in "Escrow" (Locked state) in the Nomad. It is only unlocked when the Receiving Zone confirms receipt via signed acknowledgement. If timeout, item reverts.

**2. THE HALLUCINATION LEAK**

- _Scenario:_ The LLM ignores the System Prompt and writes "You pick up the Laser Rifle" in a fantasy setting.
- _Protocol:_ **The Inventory Air-Gap.** The client UI does not render items based on text. It renders items based on the **Binary Inventory State** sent by the Logic Kernel. The text says "Laser Rifle"; the Inventory screen is empty. The player recognizes the lie immediately.

**3. THE COST SPIRAL**

- _Scenario:_ 5,000 players spam "Chat" actions, triggering 5,000 LLM calls per second.
- _Protocol:_ **Semantic Debouncing.**
  - Similar requests ("Hello", "Hi", "Greetings") are clustered by Vectorize.
  - The system serves a **Cached Response** for generic inputs.
  - The "Action Budget": Non-paying players have a rate-limited Context Window.

**4. THE RECONNECT STORM**

- _Scenario:_ A data center fails. 10,000 sockets disconnect. They all reconnect instantly.
- _Protocol:_ **Deterministic Jitter.** The client SDK is hard-coded to wait `Random(100ms, 5000ms)` before reconnecting. The `RegistryDO` shards handle the intake queue.
