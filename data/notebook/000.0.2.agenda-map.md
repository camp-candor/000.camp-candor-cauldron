# 🌍 DAY ELEVEN: THE GENESIS OF GEOMETRY (Environment)

**Objective:** Implement the `MapGenDO` to procedurally generate terrain and entities upon initial zone access. Establish the pipeline that converts a raw H3 Index into a populated, descriptive environment.
**Constraint:** **Deterministic Generation.** The same H3 Index must _always_ generate the exact same terrain and entities, even if the server is wiped.
**Toolchain:** Cloudflare Durable Objects, Simplex Noise (or similar PRNG), Protobuf.
**Total Time:** 12 Hours.

### 🕒 HOUR 0-3: THE TOPOLOGY SCHEMA (`packages/schema`)

**Goal:** Define the language of the map. The client needs to know "This hex is a Forest" and "This hex has a Ruin."

**1. The Map Protocol**
We define the structure of a Zone's geography.
**File:** `packages/schema/src/map.proto`

```protobuf
syntax = "proto3";
package codex;

// The Static Terrain of a Zone
message ZoneTerrain {
  string zone_id = 1; // H3 Res 8
  string biome = 2;   // "FOREST", "DESERT", "CRYPT"

  // Sparse Map of Features (Res 15 hexes)
  map<string, HexFeature> features = 3;
}

message HexFeature {
  enum FeatureType {
    EMPTY = 0;
    WALL = 1;
    WATER = 2;
    DIFFICULT_TERRAIN = 3;
    PORTAL = 4;
  }
  FeatureType type = 1;
  int32 height = 2; // Z-axis
  string texture_id = 3; // For client rendering
}

// The Spawn Manifest (What lives here?)
message SpawnManifest {
  repeated SpawnPoint spawns = 1;
}

message SpawnPoint {
  string entity_def_id = 1; // "def_goblin_scout"
  string h3_index = 2;      // Where they start
  string faction = 3;
}
```

### 🕒 HOUR 3-6: THE ARCHITECT (`apps/edge`)

**Goal:** Create the `MapGenDO`. This is a worker dedicated to heavy math. It takes an H3 Index and returns a `ZoneTerrain` and `SpawnManifest`.

**1. The Deterministic Math**
We need a seeded random number generator.
**File:** `apps/edge/src/utils/procgen.ts`

```typescript
import { createNoise2D } from 'simplex-noise'; // Or a custom linear congruential generator
import alea from 'alea'; // Seeded RNG

export class WorldSeeder {
  private rng: any;
  private noise: any;

  constructor(seed: string) {
    this.rng = alea(seed);
    this.noise = createNoise2D(this.rng);
  }

  getBiome(lat: number, lng: number): string {
    const n = this.noise(lat * 0.1, lng * 0.1);
    if (n > 0.5) return 'MOUNTAIN';
    if (n < -0.2) return 'SWAMP';
    return 'PLAINS';
  }

  // Determine if a specific Res 15 hex has a wall/obstacle
  getFeature(h3Index: string): string | null {
    // Hash the index to get a deterministic float 0-1
    const val = this.rng();
    if (val > 0.95) return 'WALL'; // 5% chance of wall
    return null;
  }
}
```

**2. The Map Generator Object**
**File:** `apps/edge/src/objects/MapGenDO.ts`

```typescript
import { DurableObject } from 'cloudflare:workers';
import { WorldSeeder } from '../utils/procgen';
import { cellToLatLng } from 'h3-js';

export class MapGenDO extends DurableObject {
  constructor(state: DurableObjectState, env: Env) {
    super(state, env);
  }

  async fetch(request: Request) {
    const url = new URL(request.url);

    if (url.pathname === '/generate') {
      const { zoneId } = await request.json();

      // 1. SEED THE WORLD
      // The Zone ID is the seed. This guarantees the map is always the same.
      const seeder = new WorldSeeder(zoneId);

      // 2. CALCULATE BIOME
      const [lat, lng] = cellToLatLng(zoneId);
      const biome = seeder.getBiome(lat, lng);

      // 3. GENERATE SPAWNS (Simplified)
      // If biome is SWAMP, spawn Goblins.
      const spawns = [];
      if (biome === 'SWAMP') {
        spawns.push({
          entity_def_id: 'def_goblin_scout',
          h3_index: zoneId, // Logic to find valid sub-hex omitted for brevity
          faction: 'MONSTER',
        });
      }

      // 4. RETURN MANIFEST
      return new Response(
        JSON.stringify({
          terrain: { zoneId, biome, features: {} },
          spawns: { spawns },
        })
      );
    }
    return new Response('Architect Ready');
  }
}
```

**Goal:** Connect the `ZoneDO` to the `MapGenDO`. When a player enters a "Cold" zone, the Zone must terraform itself.

**1. The Zone Hydration Logic**
**File:** `apps/edge/src/objects/ZoneDO.ts` (Update)

  // Inside ZoneDO class

  private async ensureHydrated() {
    // 1. Check if we have terrain in RAM/Storage
    const storedMap = await this.storage.get("map_data");
    if (storedMap) return; // Already exists

    console.log("[ZONE] Cold Start. Terraforming...");

    // 2. Call the Architect
    // We map ZoneID to a MapGen shard (to spread load)
    const generatorId = this.env.MAPGEN_DO.idFromName("shard_0"); // or random shard
    const generator = this.env.MAPGEN_DO.get(generatorId);

    const response = await generator.fetch("http://internal/generate", {
      method: "POST",
      body: JSON.stringify({ zoneId: this.state.id.toString() })
    });

    const { terrain, spawns } = await response.json();

    // 3. Persist Terrain
    await this.storage.put("map_data", terrain);

    // 4. Spawn Entities
    // Iterate manifest and instantiate LogicKernel entities
    for (const spawn of spawns.spawns) {
        this.kernel.spawnEntity(spawn.entity_def_id, spawn.h3_index);
    }
  }

  // Call this at the start of any User Interaction
  async fetch(request: Request) {
      await this.ensureHydrated();
      // ... handle request ...
  }
