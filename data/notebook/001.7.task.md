### **Task Name:** Task 001.13: Workspace Build Pipeline Verification

### **Task Description:**

**User Story**
As a DevOps Engineer, I want to execute a single root-level command (`npm run build`) that successfully compiles all packages and applications in the correct dependency order, so that I can certify the Monorepo architecture is structurally sound and ready for feature development.

**Context & Value**
This is the "Integration Smoke Test."
**The Strategic Value:** Deployment Confidence. If we cannot build the project locally in one shot, we cannot deploy it to Vercel or Cloudflare.
**The Technical Challenge:** Topological Sorting. The build system must build `@quartet/types` and `@quartet/config` _before_ attempting to build `apps/server` or `apps/edge`.
**The Standard:** A Zero-Warning policy is in effect.

**Technical Constraints**

- **Tooling:** `npm` workspaces (native `npm run build --workspaces --if-present`).
- **Order of Operations:** Packages -> Apps.
- **Artifacts:** verification of output folders (`dist/`, `.next/`, `worker.js`).
- **Parallelism:** Permitted, provided dependencies are respected (typically handled by `npm` or `turbo` if introduced later, but `npm` is the baseline).

---

### **Subtasks:**

**Configuration (Root Scripts)**

- [ ] Open root `package.json`.
- [ ] Define `"build"` script: `"npm run build --workspaces --if-present"`.
- [ ] (Optional/Recommended) If using `turbo` or `lerna`: Configure pipeline topology. If using native npm, ensure leaf packages (`types`, `config`) have valid build scripts.

**Execution (The Test)**

- [ ] Clean the environment: `rm -rf node_modules` (and lockfile) and run a fresh `npm install`.
- [ ] Execute `npm run build` from the root.
- [ ] Monitor the output stream. Ensure `@quartet/types` builds first.
- [ ] Ensure `@quartet/config` builds second (or parallel with types).
- [ ] Ensure `apps/*` build last.

**Verification (Artifact Inspection)**

- [ ] Check `packages/types/dist`: `index.js` and `index.d.ts` must exist.
- [ ] Check `packages/config/dist`: `index.js` must exist.
- [ ] Check `apps/server/.next`: Build manifest must exist.
- [ ] Check `apps/octo/dist`: Static assets must exist.
- [ ] Check `apps/edge`: (Note: Workers often just type-check during build, unless `wrangler deploy --dry-run` is used. Verify typescript compilation succeeds).

---

**Acceptance Criteria**

- [ ] **Validation:** The root build command exits with Code 0 (Success).
- [ ] **State:** All 5 workspaces have generated their respective build artifacts.
- [ ] **Dependency Resolution:** No "Module not found" errors regarding internal `@quartet/*` packages.
- [ ] **Timing:** The build completes in a reasonable timeframe (under 60s for an empty skeleton).
