### **I. THE DEFINITION OF TRUTH (Executive Summary)**

**The Function**
This Artifact defines the strict **Topological Execution Order** for the entire codebase. It mandates the sequence in which workspaces must compile to ensure that shared libraries (`types`, `config`) are available to consumers (`apps/*`) at build time.

**The Liability**
Failure to adhere to this topology results in **"Module Not Found"** errors during CI/CD.
A non-deterministic build order is a Critical Risk Factor. If the `server` attempts to build before `types` is ready, the deployment will fail. We do not rely on "luck" or race conditions; we rely on a strict Directed Acyclic Graph (DAG).

**The Scope of Authority**

- **GOVERNS:** The `npm run build` lifecycle, CI/CD Pipelines (Vercel/GitHub Actions), and local development scripts.
- **OVERRIDES:** Any individual `package.json` build script that attempts to bypass the root orchestration.

**1. The Dependency Graph (The Critical Path)**
The build system operates in **Tiers**. Tier 0 must complete successfully before Tier 1 begins.

- **TIER 0: THE AXIOMS (Shared Libraries)**
