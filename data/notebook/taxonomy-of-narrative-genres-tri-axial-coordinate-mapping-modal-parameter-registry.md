# Taxonomy of Narrative Genres: Tri-Axial Coordinate Mapping & Modal Parameter Registry

A systematic taxonomy and ontological mapping registering 45 discrete narrative, speculative, and tonal genres into the Tri-Axial Theory of Style (Tone, Physics, Pacing) and Doležel’s Four Modal Chambers (Alethic, Deontic, Axiological, Epistemic).

---

## 1. The Tri-Axial & Modal Architectural Mapping

Every genre archetype functions as a deterministic configuration preset within the simulation engine:
* **The Environmental Axis (Tone):** Pastoral [0.0] $\longleftrightarrow$ Grimdark [1.0]
* **The Sensory Axis (Physics):** Abstract/Frictionless [0.0] $\longleftrightarrow$ Tactile/High-Friction [1.0]
* **The Temporal Axis (Pacing):** Meditative/Contemplative [0.0] $\longleftrightarrow$ Kinetic/Accelerated [1.0]

## 2. The Horror Sub-Taxonomy (The Dark Spectrum)

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ HORROR SPECIALIZATION REGISTRY                                                         │
├──────────────────────────┬───────┬─────────┬────────┬──────────────────────────────────┤
│ Sub-Genre                │ Tone  │ Physics │ Pacing │ Core Sensory & Thematic Driver   │
├──────────────────────────┼───────┼─────────┼────────┼──────────────────────────────────┤
│ Haunting                 │ 0.75  │  0.40   │  0.25  │ Epistemic (Grief, Lingering Will)│
│ Lovecraft's Horror       │ 0.95  │  0.80   │  0.40  │ Epistemic (Cosmic Indifference)  │
│ Man-Made Horror          │ 0.85  │  0.90   │  0.65  │ Deontic (Hubris, Bio-Engineering)│
│ Monstrous Horror         │ 0.80  │  0.95   │  0.80  │ Alethic (Biological Predation)   │
│ Mythic Horror            │ 0.85  │  0.75   │  0.45  │ Axiological (Sacred Taboo Breach)│
│ Occult                   │ 0.85  │  0.70   │  0.40  │ Deontic/Epistemic (Esoteric Law) │
│ Psychic Abilities        │ 0.65  │  0.55   │  0.70  │ Alethic (Noetic Distortion)      │
│ Psychological            │ 0.80  │  0.50   │  0.35  │ Epistemic (Sensory Unreliability)│
│ Quiet Horror             │ 0.70  │  0.60   │  0.15  │ Contemplative (Dread/The Unseen) │
└──────────────────────────┴───────┴─────────┴────────┴──────────────────────────────────┘
```

* **Haunting:** Low temporal speed; high epistemic ambiguity; atmospheric chill and lingering historical trauma.
* **Lovecraft's Horror:** Absolute epistemic collapse; geometry fractures; truth unseats human cognitive sanity.
* **Man-Made Horror:** Unchecked technical hubris; industrial bio-waste, radiation sickness, and weaponized biology.
* **Monstrous Horror:** High physical impact; relentless kinetic predator pursuit; tearing flesh and bone snap.
* **Mythic Horror:** Ancient sacred terror; violating primordial covenants with deities or regional titans.
* **Occult:** Grim ritual formality; ceremonial circles, blood pacts, and strict forbidden texts.
* **Psychic Abilities:** Cognitive bleed-through; telekinetic shockwaves, cranial pressure, and perceptual distortion.
* **Psychological:** Unreliable narrator mechanics; sensory hallucination; internal dread eroding reality.
* **Quiet Horror:** Extreme *Ma* (negative space); subtle wrongness in ordinary domestic settings; zero jump scares.

## 3. The Thriller & Speculative Sub-Taxonomy

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ THRILLER & SPECULATIVE HYBRID REGISTRY                                                 │
├──────────────────────────┬───────┬─────────┬────────┬──────────────────────────────────┤
│ Sub-Genre                │ Tone  │ Physics │ Pacing │ Core Operational Engine          │
├──────────────────────────┼───────┼─────────┼────────┼──────────────────────────────────┤
│ Alien Sci Fairy          │ 0.45  │  0.35   │  0.60  │ Exobiological Mythic Synthesis   │
│ Action Thriller          │ 0.60  │  0.85   │  0.95  │ Kinetic Ballistics & Momentum    │
│ Alt History Sci-Fi       │ 0.65  │  0.80   │  0.55  │ Retro-Causal Divergence          │
│ Comedy Thriller          │ 0.35  │  0.50   │  0.85  │ Frictional Farce Under Stakes    │
│ Conspiracy Thriller      │ 0.75  │  0.65   │  0.70  │ Panoptic Paranoia & Covert State │
│ Psychological Thriller   │ 0.80  │  0.60   │  0.65  │ Interpersonal Gaslighting & Dread│

└──────────────────────────┴───────┴─────────┴────────┴──────────────────────────────────┘
```

* **Alien Sci Fairy:** Extraterrestrial exobiology framed with fairy-tale whimsy and bioluminescent wonder.
* **Action Thriller:** Maximum kinetic momentum; physical impact stops, tactical positioning, and relentless clocks.
* **Alternative History Sci-Fi:** Branching timelines where divergent engineering choices (vacuum tubes, steam, atomic batteries) dictate world ontology.
* **Comedy Thriller:** High stakes married to kinetic physical comedy and logistical misadventures.
* **Conspiracy Thriller:** High epistemic paranoia; panoptic surveillance, redacted intelligence, and institutional corruption.
* **Psychological Thriller:** Intimate interpersonal tension; deceit, claustrophobic framing, and escalating mental stakes.
* **Techno Thriller:** Procedural accuracy, cold technical jargon, military hardware specifications, and countdown deadlines.

## 4. Integration into the Configuration Pipeline

These genres map to modular configuration overlays that can be passed into `packages/config`:
```typescript
import { WorldConfig, GenreOverlay } from '@repo/types';

export function composeGenre(baseWorld: WorldConfig, genre: GenreOverlay): WorldConfig {
  return {
    ...baseWorld,
    meta: { ...baseWorld.meta, sub_genre: genre.id },
    alethic: { ...baseWorld.alethic, ...genre.alethic_overrides },
    deontic: { ...baseWorld.deontic, ...genre.deontic_overrides },
    axiological: { ...baseWorld.axiological, ...genre.axiological_overrides },
    epistemic: { ...baseWorld.epistemic, ...genre.epistemic_overrides },
  };
}
```
This ensures that whether a scene shifts into *Southern Gothic*, *Lovecraftian Horror*, *Cyberpunk*, or a *Techno-Thriller*, the underlying Logic Kernel, Render Pipeline, and Prompt Linters enforce the exact parameters required for canonical consistency.
