### How Tension Budget Solves Silent Dead Zones Event Clusters

Unattended multi-hour screenplay generators fail in two opposite ways: long stretches where random rolls miss every threshold ("nothing happens for hours"), and sudden spikes where 4 separate triggers fire on back-to-back ticks. The Pacing Tension Budget governs both cleanly in integer basis points:

1. **Global Scene Cooldown Window (`min_ticks_between_scenes`, `min_minutes_between_scenes`):** Suppresses normal sub-critical catalysts immediately after a scene fires so events have breathing room, while letting catastrophic triggers (`>= critical_override_bps`) break through cleanly.
2. **Three-Act Escalating Curve (`act_window_mode`, `act_i_end_bps`, `act_ii_end_bps`, multipliers):** Modulates dramatic sensitivity across `ACT_I` (`0.85x` baseline `8500` bp), `ACT_II` (`1.15x` `11500` bp), and `ACT_III` (`1.45x` `14500` bp) over either total simulation horizon (`HORIZON_PERCENT`), 24-hour clock time (`SOLAR_24H_CYCLE`), or multi-day span (`MULTI_DAY_ARC`).
3. **Diurnal Hour Tension Bias (`diurnal_tension_weights_bps`):** Weights every scene evaluation by narrative clock `Daypart` (`DAWN`, `MORNING`, `AFTERNOON`, `DUSK`, `NIGHT`) so midnight/dusk hours naturally amplify paranoia and late-night confrontations.
4. **Anti-Drought Pressure Accumulator (`max_dry_spell_ticks`, `drought_boost_bps_per_tick`, `max_drought_boost_bps`):** Whenever ticks without a scene reach `max_dry_spell_ticks`, tension boost grows deterministically each tick until either simmering paranoia/grievance breaks threshold or a canonical Date/Time `CHRONO_MILESTONE` fires (`droughtBreaker: true`).

## 2. Step-by-Step Blessed Terminal Menu Instructions

### Step 1: Tune Pacing Cooldowns Multipliers (`000.goblin-lore`)

1. Boot the Lore Blessed TUI:
   ```powershell
   cd D:\trellis\000.goblin-lore
   npm run tui
   ```
   (`npm run tui` starts `npx tsx apps/995.library/run.ts -t lore` -> `LORE MENU`.)
2. Select **`[S] SWITCH ACTIVE SERIES`** (or create one with **`[G] UNIVERSAL SERIES GENESIS WIZARD`**).
3. Select **`[T] SIMULATION CHRONOLOGY CLOCK`** (`day-007` chronology directive):
   - Set or confirm `start_date` (`YYYY-MM-DD`), `start_time` (`HH:MM`), and `tick_seconds` (for example `900` = 15 simulated minutes per tick, `96` ticks = 24 hours).
4. Select **`[A] CONFIGURE AUTO-SCRIPT CATALYSTS`** -> **`[5] CONFIGURE THREE-ACT PACING BUDGET`** (`day-007` Phase Five directive):
   - **`[1] SET MIN TICKS BETWEEN SCENES`** -- Enter minimum cooldown ticks between scenes (e.g. `2` or `3` for 30-45 minutes spacing at 15m/tick). Negatives, floats, or invalid integers fail closed before mutating `series.config.json`.
   - **`[2] SET MAX DRY SPELL TICKS`** -- Enter maximum silent stretch allowed before anti-drought tension pressure injects (e.g. `6` or `8` ticks = max ~2 hours silence).
   - **`[3] SET ACT I II III MULTIPLIERS (BPS)`** -- Set integer multipliers (`1000..50000`, where `10000` = `1.00x`, e.g. `8500` -> `11500` -> `14500`). Verify `act_i_end_bps < act_ii_end_bps`.
   - **`[4] TOGGLE ACT WINDOW MODE (HORIZON / 24H)`** -- Choose `HORIZON_PERCENT` for fixed-length runs or `SOLAR_24H_CYCLE` to lock tension waves to real 24-hour circadian time.
   - **`[5] PREVIEW 24H ASCII PACING CURVE`** -- Inspect the right-hand `cns00` ASCII bar curve displaying combined Act x Diurnal scaling across `DAWN`, `MORNING`, `AFTERNOON`, `DUSK`, and `NIGHT`.
   - Select **`[<] BACK TO CATALYST MENU`** -> **`[<] RETURN TO LORE MENU`**.
5. Select **`[C] COMPILE CANON & GATE 0 GAUNTLET`** to seal `pacing_budget` inside `bible-state.json` Merkle checksums and regenerate Byte-0 `world/dramatic-catalysts.md`.
6. Select **`[P] PUBLISH SEALED CANON TO SIMULATION FLEET`** and confirm pure 7-bit ASCII pacing telemetry on `cns00`:
   ```text
   >> [PUBLISH:PACING] mode=HORIZON_PERCENT cooldown=2t dryMax=6t floor24h=13
   ```

## 4. Missing High-Value Elements Future Extensions

Even with global cooldowns, three-act curve scaling, diurnal weights, and anti-drought accumulators, the following missing capabilities represent high-leverage value for subsequent phases:

1. **Per-Character Stamina Spotlight Rotation Cooldown (`actor_cooldown_ticks`):**
   - *What is missing:* Currently `min_ticks_between_scenes` is only scene-global. In an ensemble cast, the same hyper-paranoia dyad can still dominate every permitted slot while secondary characters sit idle.
   - *High-value addition:* Track `lastFeaturedTickByActor` inside `AutonomousSimState` and multiply secondary-cast candidates by a spotlight recovery bonus once an actor exceeds an `idle_spotlight_threshold_ticks` cap.
2. **Chrono Agenda Scheduled Story Appointments (`ChronoAgendaRegistry`):**
   - *What is missing:* Narrative dates and times currently drive cyclical `Daypart` biases and midnight `CHRONO_MILESTONE` crossings, but cannot schedule authored deadline beats (such as `2026-10-31 23:30` curfews, supply drops, or tribunal hearings).
   - *High-value addition:* Add optional `scheduled_beats: Array<{ isoDate, startTimeHm, beatCategory, reserveCooldownTicks }>` in `chronology` so pacing holds back minor drought triggers when an authored clock milestone is within `reserveCooldownTicks`, preventing trivial fillers from stealing tension seconds before a major plot deadline.
3. **Conductor Temporal Pacing Elasticity (`400.conductor` Pause Transition Tempo):**
   - *What is missing:* `400.conductor` currently maps transitions (`CUT TO:`, `DISSOLVE TO:`, `SMASH CUT TO:`) with fixed pause-frame defaults without reading scene `Act:` intensity (`ACT_I` vs `ACT_III`).
   - *High-value addition:* Feed `Pacing-Multiplier-Bps` from stacked Fountain metadata into `mapTransitionToPauseFrames` and room-tone decay durations so Act I lingers contemplatively on establishing shots while Act III cuts rapidly across breathless escalation.
4. **Spatial Proximity Convergence Multiplier (`301.spatial` -> `300.engine`):**
   - *What is missing:* Drought boost currently climbs purely on elapsed ticks/minutes regardless of whether characters are isolated across town or locked in the same cramped room.
   - *High-value addition:* Pipe `301.spatial` actor proximity counts (`sameRoomActorsCount`, blocked exit paths) into the pacing multiplier so overcrowded tight quarters compress cooldown recovery while solitary transit slows dramatic tempo naturally.
5. **Visual Tick-by-Tick Timeline ECG Sparkline Explorer (`98.menu.unit`):**
   - *What is missing:* Operators see `actCounts` totals and ASCII bars, but cannot inspect *where* within a 96-tick day cooldown blocks (`x`), near-misses (`.`), emitted scenes (`*`), or drought breakers (`!`) occurred without opening `index.json`.
   - *High-value addition:* Add a compact pure-ASCII 96-character tick sparkline rendered on `cns00` (`[I:..*..x..|II:..*...!..|III:.*.*!*]` with hour ruler `00h..08h..16h..24h`), giving instant visual diagnosis of flat spots or pacing spikes.
6. **Multi-Episode Momentum Hangover Seeding:**
   - *What is missing:* Multi-day episodic runs reset `lastSceneTick` and accumulated tension at episode boundaries (`totalTicks` end -> next batch start).
   - *High-value addition:* Export a sealed compact `SimulationCarryoverSeed` alongside `index.json` capturing ending simulation clock `YYYY-MM-DD HH:MM:SS`, leftover cooldown ticks, and lingering trauma/paranoia baselines so Episode 2 picks up mid-breath at `08:15` on Day 2 cleanly.
