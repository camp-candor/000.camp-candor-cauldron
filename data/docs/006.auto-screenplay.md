# Auto-Screenplay: Autonomous Rolling Simulation Runbook

> End-to-end operator guide for configuring, launching, auditing, and batch-ingesting unattended rolling Fountain screenplay stacks across the four-repository Camp Candor fleet (`000.goblin-lore`, `000.goblin-spatial`, `000.series-sower-engine`, `000.series-sower-conductor`).

---

## 1. Pipeline Architecture Across Repositories

1. **`000.goblin-lore` (`@camp_candor/299.lore`)** -- Defines narrative catalyst significance thresholds (`AutoScriptConfig`), character voice lexicons across all six Fountain categories, and canonical series chronology (`start_date`, `start_time`, `tick_seconds`). Compiles `bible-state.json` alongside Byte-0 `world/dramatic-catalysts.md` and publishes sealed canon to the fleet.
2. **`000.goblin-spatial` (`@camp_candor/301.spatial`)** -- Computes physical incident witnesses (optical line-of-sight, wall occlusion, acoustic range, diurnal illumination by time-of-day) and builds spatial stage briefs mapping each trigger onto Fountain Slugline, Action lighting/sound cues, Witness Parentheticals, and Transitions.
3. **`000.series-sower-engine` (`@camp_candor/300.engine`)** -- Executes the unattended rolling simulation loop (`1..totalTicks`) using pure deterministic PRNG (`fnv1a32` + `mulberry32Step` + `rollDeterministic2d6`). Whenever an event crosses threshold without human approval, synthesizes a complete six-category Fountain screenplay tagged with narrative `Date`, `Start-Time`, `End-Time`, `Timecode`, and `Daypart`, stacking `.fountain`, `.ast.json`, and `index.json` sequentially inside `drafts/auto-script/<seriesSlug>/`.
4. **`000.series-sower-conductor` (`@camp_candor/400.conductor`)** -- Discovers stacked auto-script directories, enforces all six Fountain screenplay categories (`Scene Heading (Slugline)`, `Action Lines`, `Character Names (Cue)`, `Parentheticals`, `Dialogue`, `Transitions`), stitches chronological episodes (`episode_manifest.json`), seals canonical JCS Merkle receipts (`stack_receipt.json`), and streams validation telemetry to Blessed console `cns00`.

> [!NOTE]
> **Implementation Status Notice:** Core Blessed TUI runners (`npm run tui` / `npm run dev`) and primary cockpit menus exist today in each repository. The new Auto-Script and Chronology TUI menu entries documented below correspond to the pending directive specifications authored in `000.goblin-lore/data/directive/day-007/002..018`, `000.goblin-spatial/data/directive/day-003/009..025`, `000.series-sower-engine/data/directive/day-004/002..018`, and `000.series-sower-conductor/data/directive/day-005/002..018`. Execute those directives with Jules and run their `.ag-test.md` suites before walking this runbook interactively.

## 2. Step-by-Step Blessed TUI Operator Runbook

### Step 1: Configure Canon Chronology Catalyst Rules (`000.goblin-lore`)

1. Launch the Lore Blessed terminal cockpit:
   ```powershell
   cd D:\trellis\000.goblin-lore
   npm run tui
   ```
   (`npm run tui` invokes `npx tsx apps/995.library/run.ts -t lore` and opens `LORE MENU`.)
2. Select **`[S] SWITCH ACTIVE SERIES`** (or **`[G] UNIVERSAL SERIES GENESIS WIZARD`** if starting a fresh series).
3. Select **`[T] SIMULATION CHRONOLOGY CLOCK`** (`day-007` chronology directive):
   - Inspect or set `start_date` (`YYYY-MM-DD`), `start_time` (`HH:MM`), and `tick_seconds`.
   - Confirm the `+5` tick horizon preview renders cleanly on `cns00`.
4. Select **`[A] CONFIGURE AUTO-SCRIPT CATALYSTS`** (`day-007` Phase Five directive):
   - **`[1] INSPECT CATALYST RULES`** -- View active dramatic thresholds and enabled trigger categories in `cns00`.
   - **`[2] SET GLOBAL SIGNIFICANCE THRESHOLD (BPS)`** -- Tune `min_global_significance_bps` (`0..10000`, e.g. `4500` for steady dramatic pacing or `2000` for dense scene output). Invalid numbers or unsafe `output_subdir` paths are rejected fail-closed before disk writes.
   - **`[3] TOGGLE EVENT CATEGORY TRIGGER`** -- Toggle trigger types (`PARANOIA_TRIGGERED`, `GRIEVANCE_BREACH`, `SOMATIC_TRAUMA`, `INVENTORY_TRANSFER`, `EPISTEMIC_REVEAL`, `CHRONO_MILESTONE`).
   - **`[4] PREVIEW CHARACTER VOICE SAMPLE`** -- Verify character voice traits compile cleanly into all six Fountain categories on `cns00`.
   - Select **`[<] RETURN TO LORE MENU`**.
5. Select **`[C] COMPILE CANON & GATE 0 GAUNTLET`** to write sealed `bible-state.json` and Byte-0 `world/dramatic-catalysts.md`.
6. Select **`[P] PUBLISH SEALED CANON TO SIMULATION FLEET`** so `301.spatial`, `300.engine`, and `400.conductor` receive matching chronology and catalyst manifests.

### Step 3: Launch Unattended Rolling Screenplay Generation (`000.series-sower-engine`)

1. Launch the Engine Blessed terminal cockpit:
   ```powershell
   cd D:\trellis\000.series-sower-engine
   npm run dev
   ```
   (Or `npm run tui` -> Engine Cockpit.)
2. Select **`[01] BOOT ENGINE & ENSURE SCHEMA`** to confirm initial engine state hydration.
3. Select **`[22] RUN UNATTENDED AUTO-SCREENPLAY SIMULATION`** (`day-004` Phase Five directive, positioned directly below `[21] EXPORT TO CONDUCTOR`).
4. Choose how to set the simulation origin:
   - **`[1] LAUNCH WITH CANON CHRONOLOGY DEFAULTS`** -- Reads `start_date`, `start_time`, `tick_seconds`, and `auto_script` rules directly from sealed `bible-state.json`, then begins rolling immediately.
   - **`[2] SET START DATE TIME TICKS SEED`** -- Prompts via the left-pane modal for explicit `startDate` (`YYYY-MM-DD`), `startTime` (`HH:MM`), `totalTicks` (e.g. `24`, `96`, or `480`), and `masterSeed` (e.g. `auto_<seriesSlug>_seed01`). Malformed calendar dates (`2025-02-29`) or invalid times (`25:99`) fail closed with `:: [AUTO:ERR]` on `cns00`.
5. Step away cleanly. The simulation executes ticks `1..totalTicks` with zero interactive prompts and zero artificial delays, streaming real-time progress onto `cns00`:
   ```text
   >> [AUTO:TIMECODE] 2026-10-31 21:03:00 | TC 21:03:00:00 | DAYPART: NIGHT | TICK 3/48
   >> [AUTO:STACKED] #0001 -> 0001_t0003_20261031-2103_PARANOIA_TRIGGERED.fountain (1482 bytes)
   >> [AUTO:DONE] Stacked 7 screenplays in drafts/auto-script/<seriesSlug>
   ```
6. Inspect the generated stack inside `D:\trellis\000.series-sower-engine\drafts\auto-script\<seriesSlug>\`:
   - `<seq4>_t<tick4>_<YYYYMMDD>-<HHMM>_<CATEGORY>.fountain` -- Standalone Fountain script stamped with `Date`, `Start-Time`, `End-Time`, `Timecode`, and `Daypart`, containing all six Fountain categories (`Scene Heading (Slugline)`, `Action Lines`, `Character Names (Cue)`, `Parentheticals`, `Dialogue`, `Transitions`).
   - `<seq4>_t<tick4>_<YYYYMMDD>-<HHMM>_<CATEGORY>.ast.json` -- Paired structured scene AST + chronology payload.
   - `index.json` -- Deterministic chronological manifest (`sequence`, `tick`, `isoDate`, `startTimeHm`, `daypart`, `category`, `fountainFile`, `astFile`, `contentSha256`) containing zero wall-clock `Date.now()` timestamps.
7. Inside the `[22]` submenu, select **`[4] EXPORT STACKED SCRIPTS TO CONDUCTOR`** to copy the verified stack into `D:\trellis\000.series-sower-conductor\data\ingress\<seriesSlug>\auto-script\`.

### Step 4: Verify Delete-All Replay Determinism

1. **Automated Cockpit Check:** Inside Engine menu `[22]`, select **`[3] RUN WIPE-RESET DETERMINISM AUDIT`**. The harness snapshots SHA-256 hashes across `drafts/auto-script/<seriesSlug>/`, wipes generated screenplays cleanly, replays the identical `startDate` / `startTime` / `totalTicks` / `masterSeed`, and asserts `0` byte divergence on `cns00`.
2. **Manual Cold Wipe Check:**
   - Capture SHA-256 digests of every `.fountain`, `.ast.json`, and `index.json` inside `D:\trellis\000.series-sower-engine\drafts\auto-script\<seriesSlug>\`.
   - Delete the entire folder:
     ```powershell
     Remove-Item -Recurse -Force "D:\trellis\000.series-sower-engine\drafts\auto-script\<seriesSlug>"
     ```
   - Relaunch Engine (`npm run dev`), open `[22]`, and execute Step 3 again using the exact same `seriesSlug`, `startDate`, `startTime`, `totalTicks`, and `masterSeed`.
   - Recompute SHA-256 hashes and confirm identical filenames, identical file sizes, and identical `contentSha256` entries in `index.json`.
