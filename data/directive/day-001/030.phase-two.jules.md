#### II. ARCHITECTURAL OBJECTIVE & DESIGN SPECIFICATIONS

Implement **Phase 1: Isolated Staging & Zero-Trust Filtration** within `progressLibrarySaga` in `00.library.unit` to guarantee that payload copies never mutate the destination directly, never leak host secrets, and resolve symlinks into real files before atomic promotion:

1. **Same-Filesystem / Sibling Staging Locality:**
* Allocate the staging directory `.tmp_staging_995_library_<nonce>` strictly within `path.dirname(targetDir)`.


* Placing the staging directory in the same parent folder guarantees that both staging and target reside on the exact same storage mount partition. This prevents microsecond POSIX atomic pointer swaps from degrading into non-atomic cross-device byte copies (`EXDEV`).




2. **Zero-Trust File Exclusion Engine (`filterZeroTrust`):**
* Implement a deterministic copy filter applied per file during staging recursion.


* Strictly filter out:
* Security & secrets: `.env`, `.env.*`, `service-account*.json`, `*.pem`, `*.key`.


* VCS tracking & configs: `.git`, `.github`.


* Volatile caches & dependencies: `node_modules`, `dist`, `coverage`, `.wrangler`, `.dev.vars*`, and `*.tsbuildinfo`.






3. **Symlink Dereferencing Invariant:**
* Configure `fs.copy` with `dereference: true` so all symbolic links are converted into physical files within the staging buffer, preventing dangling pointers when propagated into foreign repositories.




4. **Staging Error Guard & Cleanup:**
* Wrap directory creation and copying in a scoped try-catch block.


* If copying fails mid-flight, immediately purge the partial `.tmp_staging_*` folder before throwing or triggering the saga compensation handler, ensuring zero orphaned staging directories are left behind.

##### 2. Implement Zero-Trust Filtration and Staging Runner

```typescript
export const ZERO_TRUST_EXCLUDED_NAMES = new Set([
    '.env',
    '.git',
    '.github',
    'node_modules',
    'dist',
    'coverage',
    '.wrangler',
]);

export const filterZeroTrust = (srcPath: string): boolean => {
    const path = require('path');
    const base = path.basename(srcPath);

    if (ZERO_TRUST_EXCLUDED_NAMES.has(base)) return false;
    if (base.startsWith('.env.')) return false;
    if (base.startsWith('.dev.vars')) return false;
    if (base.endsWith('.tsbuildinfo')) return false;
    if (base.endsWith('.pem') || base.endsWith('.key')) return false;
    if (base.startsWith('service-account') && base.endsWith('.json')) return false;

    return true;
};

export const stageLibraryPayload = async (
    sourceDir: string,
    targetDir: string,
    nonce?: string,
): Promise<{ stagingDir: string; parentDir: string }> => {
    const fs = require('fs-extra');
    const path = require('path');

    const resolvedTarget = path.isAbsolute(targetDir)
        ? targetDir
        : path.resolve(process.cwd(), targetDir);
    const parentDir = path.dirname(resolvedTarget);
    const uniqueNonce = nonce || `${Date.now()}_${Math.random().toString(36).slice(2, 7)}`;
    const stagingDir = path.join(parentDir, `.tmp_staging_995_library_${uniqueNonce}`);

    try {
        await fs.ensureDir(stagingDir);
        await fs.copy(sourceDir, stagingDir, {
            dereference: true,
            filter: filterZeroTrust,
        });
        return { stagingDir, parentDir };
    } catch (err: any) {
        if (await fs.pathExists(stagingDir)) {
            await fs.remove(stagingDir).catch(() => {});
        }
        throw new Error(`[STAGING_FAILED] Error staging payload to ${stagingDir}: ${err.message}`);
    }
};

```

                    idx: 'cns00',
                    src: `>> [STAGING] [OK] Filtered payload staged at: ${stagingDir}`,

            // PHASE 2: ATOMIC INODE PROMOTION
            // =================================================================
            const targetExists = await fs.pathExists(resolvedTarget);

                await fs.rename(resolvedTarget, backupDir);
                sagaJournal.backups.set(resolvedTarget, backupDir);
                if (ste) {
                    await ste.hunt(ActCns.UPDATE_CONSOLE, {
                        idx: 'cns00',
                        src: `>> [BACKUP] Sibling backup created: ${backupDir}`,
                    });
                }
            }

            await fs.rename(stagingDir, resolvedTarget);

            if (await fs.pathExists(backupDir)) {
                await fs.remove(backupDir);
            }

            sagaJournal.targetsCompleted.push(resolvedTarget);

            if (ste) {
                await ste.hunt(ActCns.UPDATE_CONSOLE, {
                    idx: 'cns00',
                    src: `>> [SUCCESS] Promoted library -> ${resolvedTarget}`,
                });
            }
        } catch (err: any) {
            if (ste) {
                await ste.hunt(ActCns.UPDATE_CONSOLE, {
                    idx: 'cns00',
                    src: `>> [ERROR] Staging or swap failed on ${resolvedTarget}: ${err.message}`,
                });
            }

            if ((await fs.pathExists(backupDir)) && !(await fs.pathExists(resolvedTarget))) {
                try {
                    await fs.rename(backupDir, resolvedTarget);
                    if (ste) {
                        await ste.hunt(ActCns.UPDATE_CONSOLE, {
                            idx: 'cns00',
                            src: `>> [RESTORED] Pre-existing target restored from backup: ${resolvedTarget}`,
                        });
                    }
                } catch (restoreErr: any) {
                    if (ste) {
                        await ste.hunt(ActCns.UPDATE_CONSOLE, {
                            idx: 'cns00',
                            src: `>> [CRITICAL] Failed to restore backup: ${restoreErr.message}`,
                        });
                    }
                }
            }

            if (stagingDir && (await fs.pathExists(stagingDir))) {
                await fs.remove(stagingDir).catch(() => {});
            }

            sagaJournal.targetsFailed.push(resolvedTarget);
