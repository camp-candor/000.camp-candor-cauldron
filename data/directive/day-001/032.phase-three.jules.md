#### II. ARCHITECTURAL OBJECTIVE & DESIGN SPECIFICATIONS

Implement **Phase 2: Atomic Inode Pointer Swapping** within `progressLibrarySaga` in `00.library.unit` to replace raw in-place directory overwrites with an atomic multi-step directory pointer transition and immediate forward-recovery compensation:

```text
                  ISOLATED ATOMIC PROMOTION SEQUENCE
                                   │
               1. Discover Target via scanFleet[cite: 2]
                                   │
                                   ▼
      ┌────────────────────────────────────────────────────────┐
      │ Step A: Stage payload into temporary sibling directory │[cite: 2]
      │ <target>/../.tmp_staging_995_library_<timestamp>       │[cite: 2]
      │ (Dereference symlinks, apply zero-trust exclusions)   │[cite: 2]
      └────────────────────────────┬───────────────────────────┘
                                   │
                                   ▼
      ┌────────────────────────────────────────────────────────┐
      │ Step B: Create atomic backup of active target          │[cite: 2]
      │ fs.rename(<target>, .tmp_backup_995_library_<ts>)      │[cite: 2]
      └────────────────────────────┬───────────────────────────┘
                                   │
                                   ▼
      ┌────────────────────────────────────────────────────────┐
      │ Step C: Atomically promote staging to target           │[cite: 2]
      │ fs.rename(.tmp_staging_995_library_<ts>, <target>)     │[cite: 2]
      └────────────────────────────┬───────────────────────────┘
                                   │
                                   ▼
      ┌────────────────────────────────────────────────────────┐
      │ Step D: Verify promotion & purge temporary backup      │[cite: 2]
      │ fs.remove(.tmp_backup_995_library_<ts>)                │[cite: 2]
      └────────────────────────────────────────────────────────┘

```

1. **Same-Filesystem Inode Invariant:**
* Both `.tmp_staging_995_library_<nonce>` and `.tmp_backup_995_library_<nonce>` must reside in `path.dirname(targetDir)`.


* Sibling directory allocation on the identical physical storage mount ensures that `fs.rename` executes as an atomic pointer swap at the filesystem inode level rather than degrading into a non-atomic cross-device copy-and-delete (`EXDEV`).




2. **Cross-Platform Lock Mitigation (`retryAtomicRename`):**
* On Windows (`win32`) environments or workstations with active file handles (antivirus scanners, IDE language servers, active dev processes), directory renames can encounter transient `EBUSY` or `EPERM` collisions.


* Wrap directory rename executions in a bounded retry loop with exponential jitter (up to 5 attempts, initial 50ms backoff) before failing.




3. **Four-Step Swap Lifecycle:**
* **Step B (Atomic Backup Shift):** If `targetDir` physically exists, atomically move it to `backupDir`. Moving the target out of the path first frees the canonical directory name on strict-locking platforms.


* **Step C (Atomic Staging Promotion):** Rename `stagingDir` into `targetDir`. In POSIX environments, active readers holding open file descriptors continue reading from the unseated inode until done, while new readers immediately see the fully written tree.


* **Step D (Teardown Verification):** Verify `targetDir` exists on disk, then unlink and purge `backupDir`.




4. **Forward-Recovery Fault Compensation:**
* If Step C fails or throws mid-swap:
* If `backupDir` exists and `targetDir` is unseated or absent, immediately execute a compensating restore rename: `fs.rename(backupDir, targetDir)`.


* Purge the dangling `stagingDir` buffer to leave zero orphaned staging inodes.


* Record `resolvedTarget` in `sagaJournal.targetsFailed`.


* Stream ASCII error and compensation telemetry to `cns00`.


* Break out of the loop immediately to halt cascading fleet drift.

export const retryAtomicRename = async (
    oldPath: string,
    newPath: string,
    maxRetries = 5,
    initialDelayMs = 50,
): Promise<void> => {
    const fs = require('fs-extra');
    let attempt = 0;
    let delay = initialDelayMs;

    while (attempt < maxRetries) {
        try {
            await fs.rename(oldPath, newPath);
            return;
        } catch (err: any) {
            attempt++;
            const isLockError = err.code === 'EBUSY' || err.code === 'EPERM' || err.code === 'EACCES';
            if (!isLockError || attempt >= maxRetries) {
                throw new Error(
                    `[ATOMIC_RENAME_FAILED] Failed to rename '${oldPath}' to '${newPath}' after ${attempt} attempt(s): ${err.message}`,
                );
            }
            // Exponential jitter delay
            const jitter = Math.floor(Math.random() * 20);
            await new Promise((resolve) => setTimeout(resolve, delay + jitter));
            delay *= 2;
        }
    }
};

export const swapAtomicInodes = async (
    stagingDir: string,
    targetDir: string,
    backupDir: string,
    ste?: State,
): Promise<{ promoted: boolean; restored: boolean; error?: Error }> => {
    const fs = require('fs-extra');
    let backupCreated = false;

    try {
        const targetExists = await fs.pathExists(targetDir);

        // Step B: Atomically backup existing target if present
        if (targetExists) {
            if (ste) {
                await ste.hunt(ActCns.UPDATE_CONSOLE, {
                    idx: 'cns00',
                    src: `>> [BACKUP] Shifting active target -> ${backupDir}`,
                });
            }
            await retryAtomicRename(targetDir, backupDir);
            backupCreated = true;
        }

        // Step C: Atomically promote staging directory into target directory
        if (ste) {
            await ste.hunt(ActCns.UPDATE_CONSOLE, {
                idx: 'cns00',
                src: `>> [PROMOTION] Inode pointer swap -> ${targetDir}`,
            });
        }
        await retryAtomicRename(stagingDir, targetDir);

        // Step D: Teardown backup after verified atomic swap
        if (backupCreated && (await fs.pathExists(backupDir))) {
            await fs.remove(backupDir);
        }

        return { promoted: true, restored: false };
    } catch (swapErr: any) {
        let restored = false;

        // Immediate Forward-Recovery Compensation
        if (backupCreated && (await fs.pathExists(backupDir)) && !(await fs.pathExists(targetDir))) {
            try {
                await retryAtomicRename(backupDir, targetDir);
                restored = true;
                if (ste) {
                    await ste.hunt(ActCns.UPDATE_CONSOLE, {
                        idx: 'cns00',
                        src: `>> [COMPENSATION] Target restored from sibling backup: ${targetDir}`,
                    });
                }
            } catch (restoreErr: any) {
                if (ste) {
                    await ste.hunt(ActCns.UPDATE_CONSOLE, {
                        idx: 'cns00',
                        src: `>> [CRITICAL] Failed to restore backup: ${restoreErr.message}`,
                    });
                }
            }
        }

        // Purge orphaned staging directory
        if (await fs.pathExists(stagingDir)) {
            await fs.remove(stagingDir).catch(() => {});
        }

        return { promoted: false, restored, error: swapErr };
    }
};
