### II. ARCHITECTURAL MISSION & REQUIREMENTS

The monorepo engine currently suffers from a version divergence where the root `package.json` (`0.2.0`) and `apps/995.library/package.json` (`1.0.12`) are desynchronized:

1. **The Flawed Assumption in `bump-version.yml`:** The legacy workflow used `npm version --no-workspaces` and explicitly failed if `apps/` had any modifications. This prevented the core library manifest in `apps/995.library` from tracking the root release version.


2. **The Missing Gate in `release.yml`:** The release workflow previously verified git tag syntax (`v*.*.*`) but never verified that the internal workspace manifests actually matched the tag being published.


3. **The Synchronization Model:**
* Step A: Increment root `package.json` using `npm version <bump_type> --no-git-tag-version`.


* Step B: Read the newly computed SemVer and write it across all discovered `apps/*/package.json` files.


* Step C: Regenerate root `package-lock.json` workspace graphs using `npm install --package-lock-only`.


* Step D: Commit the manifests and create the signed/annotated git tag `v<version>`.


* Step E: Assert that `packages/` remains untouched while `apps/` is 100% aligned with root SemVer.


* Step F: Push commit and tag to remote trunk, triggering `release.yml`.


* Step G: In `release.yml`, assert that `package.json` and all `apps/*/package.json` versions match the git tag before minting the GitHub release.

### III. FILE IMPLEMENTATION MANIFEST

#### 1. Overwrite: `.github/workflows/bump-version.yml`

```yaml
name: Bump Version & Dispatch Release

on:
    workflow_dispatch:
        inputs:
            bump_type:
                description: 'SemVer release increment level'
                required: true
                default: 'patch'
                type: choice
                options:
                    - patch
                    - minor
                    - major

concurrency:
    group: bump-version-${{ github.ref }}
    cancel-in-progress: false

permissions:
    contents: write

env:
    HUSKY: 0

jobs:
    bump:
        name: validate and bump root version
        runs-on: ubuntu-latest
        steps:
            - name: Checkout Repository with Tags
              uses: actions/checkout@v4
              with:
                  fetch-depth: 0
                  token: ${{ secrets.GH_TOKEN || secrets.GITHUB_TOKEN }}

            - name: Setup Node Runtime
              uses: actions/setup-node@v4
              with:
                  node-version: '20'
                  cache: npm

            - name: Install Monorepo Dependencies
              run: npm ci

            - name: Pre-Bump Static TypeScript Compilation
              run: npm run check:types

            - name: Pre-Bump Monorepo Test Gauntlet
              run: npm test

            - name: Assert Pre-Bump Runner Boundary
              run: npm run check:boundary

            - name: Configure Git Committer Identity
              run: |
                  git config user.name "github-actions[bot]"
                  git config user.email "github-actions[bot]@users.noreply.github.com"

            - name: Execute Synchronized Version Bump
              run: |
                  echo ">> Executing SemVer bump: ${{ inputs.bump_type }}..."
                  npm version ${{ inputs.bump_type }} --no-git-tag-version
                  NEW_VERSION=$(node -e "console.log(require('./package.json').version)")
                  NEW_TAG="v${NEW_VERSION}"
                  echo ">> Target version: ${NEW_VERSION} (${NEW_TAG})"

                  echo ">> Synchronizing apps/ workspaces to ${NEW_VERSION}..."
                  node -e "
                    const fs = require('fs');
                    const path = require('path');
                    const rootVer = require('./package.json').version;
                    const appsDir = path.resolve('apps');
                    if (fs.existsSync(appsDir)) {
                      for (const item of fs.readdirSync(appsDir)) {
                        const pkgPath = path.join(appsDir, item, 'package.json');
                        if (fs.existsSync(pkgPath)) {
                          const pkg = JSON.parse(fs.readFileSync(pkgPath, 'utf8'));
                          pkg.version = rootVer;
                          fs.writeFileSync(pkgPath, JSON.stringify(pkg, null, 4) + '\n', 'utf8');
                          console.log('>> [SYNC] ' + pkgPath + ' -> ' + rootVer);
                        }
                      }
                    }
                  "

                  echo ">> Updating lockfile references..."
                  npm install --package-lock-only

                  git add package.json package-lock.json apps/*/package.json
                  git commit -m "chore(release): v${NEW_VERSION}"
                  git tag -a "${NEW_TAG}" -m "chore(release): v${NEW_VERSION}"
                  echo ">> Successfully committed and tagged: ${NEW_TAG}"

            - name: Assert Boundary Integrity Post-Bump
              run: |
                  echo ">> Verifying packages/ workspaces were not mutated..."
                  if [ -n "$(git status -s packages/)" ]; then
                    echo "::error::CRITICAL BREACH: packages/ workspace mutated during version bump!"
                    git status -s packages/
                    exit 1
                  fi

                  echo ">> Verifying apps/ workspaces match root version..."
                  node -e "
                    const fs = require('fs');
                    const path = require('path');
                    const rootVer = require('./package.json').version;
                    const appsDir = path.resolve('apps');
                    if (fs.existsSync(appsDir)) {
                      for (const item of fs.readdirSync(appsDir)) {
                        const pkgPath = path.join(appsDir, item, 'package.json');
                        if (fs.existsSync(pkgPath)) {
                          const v = JSON.parse(fs.readFileSync(pkgPath, 'utf8')).version;
                          if (v !== rootVer) {
                            console.error('::error::Version mismatch in ' + pkgPath + ': ' + v + ' != ' + rootVer);
                            process.exit(1);
                          }
                        }
                      }
                    }
                    console.log('>> [OK] All apps/ workspace manifests match root v' + rootVer);
                  "
                  npm run check:boundary

            - name: Push Commit and Tag to Remote Trunk
              env:
                  GH_TOKEN: ${{ secrets.GH_TOKEN || secrets.GITHUB_TOKEN }}
              run: |
                  echo ">> Pushing bump commit and tag to origin main..."
                  git push origin main --follow-tags
                  echo ">> [OK] Tag pushed successfully. Companion release.yml workflow will handle publication."

```

#### 2. Overwrite: `.github/workflows/release.yml`

```yaml
name: Publish GitHub Release

on:
    push:
        tags:
            - 'v*.*.*'

concurrency:
    group: release-${{ github.ref }}
    cancel-in-progress: false

permissions:
    contents: write

env:
    HUSKY: 0

jobs:
    release:
        name: verify and publish release
        runs-on: ubuntu-latest
        steps:
            - name: Checkout Full Repository History
              uses: actions/checkout@v4
              with:
                  fetch-depth: 0

            - name: Setup Node Runtime
              uses: actions/setup-node@v4
              with:
                  node-version: '20'
                  cache: npm

            - name: Install Monorepo Dependencies
              run: npm ci

            - name: Assert Synchronized Workspace Versions
              env:
                  TAG_NAME: ${{ github.ref_name }}
              run: |
                  echo ">> Validating that root and apps/ package versions match release tag: ${TAG_NAME}..."
                  node -e "
                    const fs = require('fs');
                    const path = require('path');
                    const refTag = process.env.TAG_NAME || '';
                    const expectedVer = refTag.replace(/^v/, '');
                    const rootVer = require('./package.json').version;

                    if (rootVer !== expectedVer) {
                      console.error('::error::Root package.json (' + rootVer + ') does not match tag ' + refTag);
                      process.exit(1);
                    }

                    const appsDir = path.resolve('apps');
                    if (fs.existsSync(appsDir)) {
                      for (const item of fs.readdirSync(appsDir)) {
                        const pkgPath = path.join(appsDir, item, 'package.json');
                        if (fs.existsSync(pkgPath)) {
                          const childVer = JSON.parse(fs.readFileSync(pkgPath, 'utf8')).version;
                          if (childVer !== expectedVer) {
                            console.error('::error::Mismatch in ' + pkgPath + ' (' + childVer + ' != ' + expectedVer + ')');
                            process.exit(1);
                          }
                        }
                      }
                    }
                    console.log('>> [OK] Root and apps/ manifests are synchronized with tag: ' + refTag);
                  "

            - name: Verify Static TypeScript Project References
              run: npm run check:types

            - name: Execute Full Monorepo Test Gauntlet
              run: npm test

            - name: Assert Immutable Runner Boundary
              run: |
                  if [ -n "$(git status -s apps/995.library/995.library/)" ]; then
                    echo "::error::IMMUTABLE HARNESS BOUNDARY BREACHED in apps/995.library/995.library/"
                    git status -s apps/995.library/995.library/
                    exit 1
                  fi

            - name: Mint and Publish GitHub Release
              env:
                  GH_TOKEN: ${{ secrets.GH_TOKEN || secrets.GITHUB_TOKEN }}
                  GITHUB_TOKEN: ${{ secrets.GH_TOKEN || secrets.GITHUB_TOKEN }}
              run: |
                  TAG_NAME="${{ github.ref_name }}"
                  echo "Publishing automated GitHub Release for ${TAG_NAME}..."
                  gh release create "${TAG_NAME}" \
                    --title "${TAG_NAME}: Edge DevOps Control Plane & Autonomous Agent Boilerplate" \
                    --generate-notes \
                    --latest

```
